# C++ Expense Tracker

A command-line expense management application developed using C++.

## Features

* Add expenses with category and amount.
* View all expenses.
* Calculate total expenses.
* Handle invalid inputs.

## Technologies Used

* C++
* Vectors and Structures

## How to Run

Compile using:

g++ main.cpp -o ExpenseTracker

## Project Type

Internship Project - Reliable Command-Line Utility
